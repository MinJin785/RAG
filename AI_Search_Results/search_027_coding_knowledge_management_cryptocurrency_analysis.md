## 압축파일 활용 가능성
- **내가 압축파일을 직접 처리할 수 없습니다**
- .zip, .rar, .7z 등의 압축파일은 압축을 풀어서 제공해 주시는 것이 효율적
- 압축된 상태에서는 내부 파일 구조나 내용을 확인할 수 없음

## 1. 코딩 지식 관리 시스템

### The Last RAG (TLRAG) - 혁신적 접근 방식
- **핵심 개념**: LLM을 일회성 도구에서 지속적 학습 파트너로 전환
- **동적 작업 공간(DWS)**: 매 쿼리마다 관련 정보를 지능적으로 조합
- **지속적 메모리**: 단순 팩트가 아닌 컨텍스트와 의미를 포함한 리치 메모리
- **비용 효율성**: 기존 RAG 대비 최대 98% 비용 절감

### Microsoft GraphRAG
- **지식 그래프 구축**: 문서에서 엔티티와 관계를 자동 추출
- **커뮤니티 탐지**: 연관된 엔티티들을 클러스터링
- **계층적 요약**: 다층 수준의 정보 조직화
- **글로벌 쿼리**: 전체 코퍼스에 대한 포괄적 답변 생성

### 개인 지식 기반 구축 방법
```python
# GitHub Copilot을 활용한 개인 지식 학습 시스템
from langchain.document_loaders import TextLoader
from langchain.vectorstores import Chroma
from instructor_embedding import INSTRUCTOR

docs = TextLoader("/my/coding/notes/").load()
embeddings = INSTRUCTOR()
db = Chroma.from_documents(docs, embedding=embeddings)

# 쿼리 예시
response = db.similarity_search("Python 디버깅 최적 방법")
```

## 2. 실용적 코딩 지식 누적 방법론

### Context Engineering for Claude Code
- **컨텍스트 = 성능의 핵심**: 프롬프트가 아닌 컨텍스트가 결정적
- **3가지 핵심 요소**:
  1. 프로젝트 아키텍처 지식 (CLAUDE 파일)
  2. 제품 요구사항 문서 (*.prd.md)
  3. 심화 기술 지식 (연구 도구로 생성)

### 지식 파일 생성 워크플로우
1. **OpenAI Deep Research**: 포괄적 초기 분석 (25-36페이지)
2. **Claude Research**: 빠른 검증 및 정제 (7페이지, 2-5분)
3. **통합 및 적용**: 실무 적용 가능한 지식 문서 생성

### 비용 최적화 전략
- Deep Research: $40-70/세션 (100,000+ 토큰)
- Claude Research: 표준 대화의 15배 비용
- 사전 계산된 지식 문서 활용으로 실시간 비용 절감

# AI민진 프로젝트 BugBot 리뷰 가이드라인

## 보안 중점 영역

- API 키 및 민감한 정보 하드코딩 검사
- 파일 시스템 접근 권한 검증
- 사용자 입력 검증 (SQL 인젝션, XSS 등)
- 환경변수 및 설정 파일 보안

## 아키텍처 패턴

- 비동기 함수 사용 일관성 (`async/await`)
- 예외 처리 패턴 (`try/except`) 완성도
- 모듈 임포트 순서 및 구조
- 메모리 효율적인 코드 작성

## AI/RAG 시스템 특화 검사

- 메모리 누수 방지 (대용량 데이터 처리)
- API 호출 제한 및 에러 핸들링
- 벡터 데이터베이스 쿼리 최적화
- 대화 컨텍스트 관리 효율성

## 일반적인 이슈

- 파일 경로 처리 (Windows/Linux 호환성)
- 로깅 레벨 및 메시지 일관성
- 데이터베이스 연결 관리
- 비동기 작업 타임아웃 설정

## 코드 품질

- 함수명 및 변수명 일관성 (한국어 주석 + 영어 코드)
- 긴 함수 분리 제안
- 중복 코드 제거
- 타입 힌트 사용 권장

## 성능 최적화

- 무거운 연산의 병렬 처리
- 캐싱 전략 적용
- 불필요한 API 호출 방지
- 메모리 사용량 모니터링

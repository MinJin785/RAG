AI민진 담당 Cursor에게 추가 전달사항

작성일: 2025년 8월 1일 01:35 (KST)
발신: RAG_Blog 프로젝트 담당자
수신: AI민진 프로젝트 담당 Cursor

【중요한 검색 방식 변경】

30번 검색 시스템 변경사항:

1. 검색 방식 변경
   - 기존: 5개 카테고리 × 6개씩 = 30개 다양한 주제
   - 변경: 1개 주제 × 30가지 각도 = 집중 심층 분석

2. 새로운 검색 패턴
   - 기본 정보 (1-5번): 주제, 최신 현황, 2025년, 통계, 데이터
   - 비교 분석 (6-10번): 전년 대비, 역대 최고, 순위, 타 학교 비교, 경쟁률
   - 상세 분석 (11-15번): 분석, 원인, 요인, 배경, 특징
   - 관련 키워드 (16-20번): 입시, 진학, 합격, 교육, 학습
   - 전망/예측 (21-25번): 전망, 예상, 미래, 계획, 목표
   - 관련 이슈 (26-30번): 이슈, 문제, 해결, 개선, 후기

3. 사용 예시
   - 입력: "2025년도 대일외고 서울대 입학생수"
   - 실행: 이 주제를 30가지 각도로 검색
   - 결과: 해당 주제에 대한 완전한 데이터셋

4. 장점
   - 하나의 블로그 글을 위한 완벽한 리서치
   - 다각도 분석으로 깊이 있는 콘텐츠 제작 가능
   - 경쟁사가 놓친 정보까지 수집 가능
   - SEO에 필요한 관련 키워드 자동 발굴

5. 파일 시스템
   - 메인 파일: focused_30_search_system.py
   - 결과 파일: focused_search_주제명_날짜시간.json
   - 리포트: focused_summary_주제명_날짜시간.md

6. 시간 표준화
   - 모든 시간은 한국 표준시(KST) 사용
   - 날짜 형식: 2025년 8월 1일 01:35 (KST)
   - 파일명: 20250801_013500 형식

7. 실행 방법
   - python focused_30_search_system.py
   - 주제 입력 후 자동 30번 검색
   - 3초 딜레이로 API 제한 회피

이 시스템을 AI민진 프로젝트에도 적용하여
하나의 주제에 대한 완벽한 리서치 시스템으로 활용하시기 바랍니다.

날짜/시간 참조 표준 규칙

적용 대상: RAG_Blog + AI민진 프로젝트

【날짜/시간 참조 표준화】

1. 기준 시간대
   - 한국 표준시 (KST, UTC+9) 사용
   - 모든 로그, 파일명, 리포트에 KST 기준 적용

2. 날짜 형식 통일
   - 한국어: 2025년 8월 1일
   - 영어/로그: 2025-08-01
   - 파일명: 20250801_HHMMSS 형식

3. 시간 형식 통일
   - 24시간 형식 사용: 01:30 (AM/PM 사용 안함)
   - 초 단위 필요시: 01:30:45
   - 파일명: HHMMSS (시분초)

4. datetime 라이브러리 사용법
   ```python
   from datetime import datetime
   import pytz
   
   # KST 기준 현재 시간
   kst = pytz.timezone('Asia/Seoul')
   now = datetime.now(kst)
   
   # 표준 형식
   korean_format = now.strftime('%Y년 %m월 %d일 %H:%M')
   iso_format = now.strftime('%Y-%m-%d %H:%M:%S')
   filename_format = now.strftime('%Y%m%d_%H%M%S')
   ```

5. 파일명 규칙
   - 검색 결과: google_search_20250801_013045.json
   - 리포트: blog_report_20250801_013045.md
   - 백업: backup_20250801_013045.zip

6. 로그 기록 규칙
   - 모든 작업 시작/완료 시간 기록
   - [2025-08-01 01:30:45] 작업명: 상태 형식
   - 예: [2025-08-01 01:30:45] Google API Search: 완료

7. 리포트 헤더 표준
   - 생성일시: 2025년 8월 1일 01:30 (KST)
   - 마지막 업데이트: 2025년 8월 1일 01:30 (KST)

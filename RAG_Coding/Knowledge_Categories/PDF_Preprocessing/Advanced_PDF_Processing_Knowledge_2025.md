# 고급 PDF 전처리 지식 (2025년 최신 기술)

## 1. OmniDocBench 벤치마크 기술 (2024-2025)

### 핵심 특징
- **멀티레벨 평가**: 19개 레이아웃 카테고리, 15개 속성 라벨
- **다양한 문서 소스**: 학술 논문, 교과서, 손글씨, 고밀도 신문
- **평가 방식**: 엔드투엔드 평가부터 태스크별/속성별 분석까지

### 우리 시스템 적용 가능성
- **레이아웃 분석 개선**: 현재 단순 텍스트 추출에서 19개 카테고리 분류로 업그레이드
- **속성 기반 처리**: 15개 속성을 활용한 정밀 문서 분류

## 2. Hybrid Document Layout Analysis (2024)

### Query Encoding Strategy 
- **고수준 쿼리 특징**: ResNet 백본에서 초기 레이어 특징 추출
- **Self-Attention 메커니즘**: 고수준과 디코더 쿼리 특징 융합
- **코사인 유사도**: 쿼리 간 유사성 계산으로 정확도 향상

### Hybrid Matching Scheme
- **One-to-Many 매칭**: 단일 객체를 다중 ground truth와 연결
- **One-to-One 매칭**: 전통적 방식과 결합으로 중복 제거
- **성능 개선**: PubLayNet 97.3%, DocLayNet 81.6% 달성

## 3. olmOCR 오픈소스 PDF 처리 (2025)

### 핵심 혁신
- **7B 비전 언어 모델**: 260,000 페이지 다양한 PDF로 파인튜닝
- **비용 효율성**: 100만 페이지당 176 USD (GPT-4o 대비 35배 저렴)
- **다양한 문서 지원**: 그래픽, 손글씨, 저품질 스캔 포함

### 기술적 특징
- **자연 읽기 순서**: 구조화된 콘텐츠 보존 (섹션, 테이블, 리스트, 수식)
- **배치 처리 최적화**: vLLM, SGLang 백엔드 지원
- **하드웨어 확장성**: 다양한 하드웨어 설정에 유연 대응

## 4. 멀티페이지 문서 분류 기술 (2024)

### 새로운 분류 체계
1. **페이지 분류 (f_p)**: 단일 페이지 카테고리화
2. **문서 분류 (f_d)**: 고정된 L개 페이지 문서
3. **문서 번들 분류 (f_b)**: 가변 개수 문서 처리
4. **페이지 스트림 분류 (f_s)**: 순서 무관 페이지 처리
5. **페이지 분할 (f_m)**: 멀티페이지 이미지 내 페이지 타입 분류

### 추론 전략
- **샘플링**: 첫 페이지, 마지막 페이지 등 특정 페이지 선택
- **시퀀스**: 최대 신뢰도, 소프트 투표, 하드 투표
- **그리드**: 모든 페이지 타일링으로 동시 처리

## 5. MLLM 기반 VRD 이해 (2025)

### OCR-Free vs OCR-Dependent
- **OCR-Free**: 직접 이미지에서 텍스트와 레이아웃 이해
- **OCR-Dependent**: OCR 결과를 멀티모달 모델에 입력

### 훈련 패러다임
- **사전훈련**: 대규모 문서 이미지로 자기지도학습
- **지시-응답 튜닝**: 특정 태스크 성능 최적화
- **모듈별 학습**: 텍스트, 비전, 레이아웃 인코더 개별 조정

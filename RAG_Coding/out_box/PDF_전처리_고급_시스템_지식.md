# PDF 전처리 고급 시스템 구축 지식

## 분석 출처

- 분석일: 2025-01-03
- 스크립트 길이: 980줄 (약 15분 44초)

## 핵심 문제점 및 해결책

### 기존 PDF 처리의 한계
1. **텍스트만 추출시 문제점**
   - 차트, 이미지, 표 누락 발생
   - 표의 임베딩이 질문과 매칭되지 않음
   - 단순 텍스트 추출로는 80-90점 수준 한계

2. **기존 파서의 문제점**
   - 제목과 일반 텍스트 구분 불가
   - 이미지 정보 손실
   - 표 데이터의 구조적 손실
   - 컨텍스트 리트리버에서 표가 검색되지 않음

### 고급 전처리 시스템 해결책

## 1. 핵심 기술 스택

### Upstage Layout Analysis API
- **역할**: PDF 요소별 분리 및 좌표 추출
- **장점**: 
  - 30달러 무료 크레딧 제공
  - 높은 정확도 및 가성비
  - 텍스트/이미지/테이블 자동 분류
- **출력**: JSON 형식의 바운딩 박스 좌표

### 요소별 분류 시스템
```
카테고리 분류:
- figure: 이미지
- table: 테이블
- paragraph: 본문
- heading: 제목
- footer: 각주
```

## 2. 시스템 아키텍처

### 파일 처리 워크플로우
1. **문서 분할**: 100페이지씩 분할하여 API 오류 방지
2. **레이아웃 분석**: Upstage API로 요소 추출
3. **좌표 기반 크로핑**: PDF에서 정확한 이미지 추출
4. **요소별 분리**: 텍스트/이미지/테이블 개별 처리
5. **배치 처리**: 병렬 처리로 속도 최적화
6. **마크다운 변환**: 구조화된 문서 생성

### 데이터 구조 설계
```python
데이터 구조:
{
    "페이지번호": {
        "elements": {...},
        "images": {...},
        "tables": {...},
        "texts": {...},
        "summaries": {...}
    }
}
```

## 3. 고급 처리 기법

### 이미지 처리
- **정확한 크로핑**: 좌표 기반 이미지 추출
- **페이지 정보 보존**: 페이지 번호 기록
- **고품질 유지**: PDF를 이미지로 변환 후 크로핑
- **컨텍스트 활용**: 주변 텍스트와 함께 이미지 설명 생성

### 테이블 처리
- **이중 처리 방식**:
  1. HTML 코드로 테이블 구조 추출
  2. 이미지로 캡처하여 멀티모달 처리
- **마크다운 변환**: 구조화된 테이블 생성
- **엔티티 추출**: 테이블 내용 서머리 생성

### 텍스트 처리
- **구조 보존**: 제목/본문/각주 구분
- **청킹 최적화**: 두 칸 띄어쓰기로 RecursiveCharacterTextSplitter 대응
- **계층 구조**: 헤딩 레벨별 분류

## 4. 성능 최적화

### 배치 처리 시스템
- **속도 향상**: 1분 30초 → 5.5초 (약 16배 향상)
- **병렬 처리**: 여러 요소 동시 처리
- **메모리 효율성**: 페이지별 분할 처리

### ID 관리 시스템
- **연속 ID 할당**: 분할 파일 간 ID 연속성 보장
- **요소별 ID**: 이미지(15, 23, 29), 테이블(12, 18, 32) 등
- **참조 무결성**: 원본 요소 추적 가능

## 5. 최종 출력물

### 마크다운 결과물
- **완전한 구조 변환**: 양면 레이아웃 → 단일 컬럼
- **이미지 경로 삽입**: 마크다운 문법으로 이미지 연결
- **표 구조 보존**: 완전한 마크다운 테이블
- **제목 계층**: 헤딩 레벨 자동 적용

### 메타데이터 구조
```python
최종 결과물:
{
    "file_path": "원본 PDF 경로",
    "batch_size": "처리 배치 크기",
    "page_elements": "페이지별 요소 정보",
    "images": "이미지 파일 경로",
    "tables": "테이블 데이터",
    "texts": "텍스트 내용",
    "text_summary": "텍스트 요약",
    "image_summary": "이미지 설명",
    "table_summary": "테이블 요약",
    "table_markdown": "마크다운 테이블"
}
```

## 6. 고급 활용 전략

### 벡터 데이터베이스 저장
- **요소별 저장**: 텍스트/이미지/테이블 개별 벡터화
- **메타데이터 활용**: ID 기반 원본 요소 참조
- **컨텍스트 보강**: 주변 정보와 함께 임베딩

### 검색 최적화
- **멀티모달 검색**: 텍스트와 이미지 동시 검색
- **구조화된 검색**: 표 데이터 전용 검색
- **컨텍스트 리트리벌**: 관련 요소 묶음 반환

## 7. 실제 적용 결과

### 품질 향상
- **답변 밀도 증가**: 표와 이미지 정보 포함
- **정확도 향상**: 구조화된 데이터 활용
- **컨텍스트 리치**: 주변 정보 활용한 설명

### 성능 개선
- **처리 속도**: 배치 처리로 16배 향상
- **메모리 효율**: 페이지별 분할 처리
- **확장성**: 대용량 문서 처리 가능

## 8. 구현시 주의사항

### API 사용 최적화
- **파일 분할**: 100페이지 단위 처리
- **배치 크기**: 메모리 용량에 맞는 조정
- **오류 처리**: API 실패시 재시도 로직

### 데이터 무결성
- **ID 연속성**: 분할 파일 간 ID 관리

- **메타데이터**: 완전한 추적 정보 보존

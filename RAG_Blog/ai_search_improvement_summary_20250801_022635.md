## 🚀 AI 검색 능력 향상 핵심 방법론

### 1. 검색 쿼리 최적화 전략
- **단계적 접근**: 기본 키워드 → 세부 키워드 → 롱테일 키워드
- **의도 파악**: 정보성/상업성/거래성 의도 구분
- **컨텍스트 활용**: 검색 목적과 배경 정보 반영

### 2. 정보 검증 및 신뢰성 평가
- **소스 다양화**: 여러 출처에서 정보 수집
- **교차 검증**: 동일 정보의 다른 소스 확인
- **최신성 체크**: 정보의 발행/업데이트 날짜 확인

### 3. 수익화 기회 발굴 전략
- **키워드 모니터링**: 수익 관련 키워드 자동 탐지
- **트렌드 분석**: 새로운 비즈니스 기회 파악
- **경쟁사 연구**: 성공 사례 벤치마킹

### 4. 실제 적용 방법
- 모든 검색에 위 방법론 적용
- 검색 결과 체계적 분석 및 기록
- 수익화 기회 발견 시 즉시 보고
- 지속적인 방법론 개선 및 업데이트

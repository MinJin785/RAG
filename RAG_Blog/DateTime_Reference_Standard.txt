작성일: 2025년 8월 1일 01:30
적용 대상: RAG_Blog + AI민진 프로젝트

【날짜/시간 참조 표준화】

1. 기준 시간대
   - 한국 표준시 (KST, UTC+9) 사용
   - 모든 로그, 파일명, 리포트에 KST 기준 적용

2. 날짜 형식 통일
   - 한국어: 2025년 8월 1일
   - 영어/로그: 2025-08-01
   - 파일명: 20250801_HHMMSS 형식

3. 시간 형식 통일
   - 24시간 형식 사용: 01:30 (AM/PM 사용 안함)
   - 초 단위 필요시: 01:30:45
   - 파일명: HHMMSS (시분초)

4. datetime 라이브러리 사용법
   ```python
   from datetime import datetime
   import pytz
   
   # KST 기준 현재 시간
   kst = pytz.timezone('Asia/Seoul')
   now = datetime.now(kst)
   
   # 표준 형식
   korean_format = now.strftime('%Y년 %m월 %d일 %H:%M')
   iso_format = now.strftime('%Y-%m-%d %H:%M:%S')
   filename_format = now.strftime('%Y%m%d_%H%M%S')
   ```

5. 파일명 규칙
   - 검색 결과: google_search_20250801_013045.json
   - 리포트: blog_report_20250801_013045.md
   - 백업: backup_20250801_013045.zip

6. 로그 기록 규칙
   - 모든 작업 시작/완료 시간 기록
   - [2025-08-01 01:30:45] 작업명: 상태 형식
   - 예: [2025-08-01 01:30:45] Google API Search: 완료

7. 리포트 헤더 표준
   - 생성일시: 2025년 8월 1일 01:30 (KST)
   - 마지막 업데이트: 2025년 8월 1일 01:30 (KST)
   - 데이터 기준일: 2025년 8월 1일

8. API 호출 시간 기록
   - 요청 시간: KST 기준 기록
   - 응답 시간: KST 기준 기록
   - 처리 시간: 초 단위 기록

9. 주의사항
   - 절대 과거 날짜로 잘못 기록하지 않기
   - 모든 타임스탬프는 실시간 생성
   - 시간대 혼동 방지를 위해 항상 KST 명시

## 검색 최적화 방법론 종합 분석

### 핵심 검색 최적화 원칙
1. **기본부터 시작**: 단순 키워드 우선 검색
2. **키워드 클러스터링**: 관련 키워드들을 그룹으로 묶어 다각도 접근
3. **체계적 사이트 분석**: 메인 페이지 → 하위 페이지 순서
4. **경쟁사 분석 활용**: 성공한 결과들 우선 분석
5. **검색 의도 파악**: 사용자가 진짜 찾는 것이 무엇인지 이해

### AI민진 프로젝트 적용 가이드
- 모든 검색은 **구글 API만 사용**
- **30번 검색 = 1개 주제** 집중 분석
- **3초 딜레이** 의무적 적용
- **KST 시간 기준** 모든 로그 작성
- **JSON + 마크다운** 이중 저장

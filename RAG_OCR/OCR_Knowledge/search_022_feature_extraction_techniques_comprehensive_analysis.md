# 특징 추출 기법 (CNN 및 Transformer 기반) - 종합 분석

## 연구 개요
날짜: 2025.08.02
주제: OCR을 위한 CNN 및 Transformer 기반 특징 추출 기법의 최신 동향
시각: CNN 아키텍처, Transformer 모델, 하이브리드 접근법, 한국어 최적화, 위치 기반 모델

## 1. CNN 기반 특징 추출 기법

### 1.1 전통적 CNN 아키텍처

#### **ResNet 기반 접근법**
- **핵심 기술**: 잔차 연결을 통한 깊은 네트워크 학습
- **장점**: 
  - 그라디언트 소실 문제 해결
  - 깊은 네트워크에서도 안정적 학습
  - 다양한 스케일의 특징 추출 가능
- **단점**: 
  - 높은 계산 복잡도
  - 메모리 사용량 증가
- **실제 성능**: 96% 이상의 정확도 (표준 데이터셋)

#### **VGG 계열 모델**
- **특징**: 작은 필터 크기(3x3)를 사용한 깊은 네트워크
- **응용**: 문자 인식에서 세밀한 특징 추출
- **한계**: 파라미터 수가 많아 과적합 위험성

### 1.2 한국어 특화 CNN 모델

#### **SDA-Net (Stroke-Sensitive Attention and Dynamic Context Encoding Network)**
- **개발 목적**: 한국어 문자의 복잡한 구조 인식
- **핵심 기술**:
  1. **Dual Attention Mechanism**: 획 단위 및 공간적 특징 추출 강화
  2. **Dynamic Context Encoding**: 학습 가능한 게이팅 메커니즘으로 의미 정보 개선
  3. **U-Net inspired Feature Fusion**: 저수준과 고수준 특징 결합
  4. **Lightweight Backbone**: 메모리 및 계산 부담 감소

- **성능 특징**:
  - 실시간 추론 속도 달성
  - 엣지 기반 OCR 시스템에 적합
  - 획 수준의 세밀한 인식 가능

#### **한국어 문자 인식의 도전과제**
- **복잡한 조합 구조**: 초성, 중성, 종성의 조합
- **유사 문자 구별**: 'ㅁ'과 'ㅂ', 'ㅗ'와 'ㅛ' 등
- **문맥적 변형**: 조합에 따른 글자 모양 변화

## 2. Transformer 기반 특징 추출

### 2.1 Vision Transformer (ViT) 계열

#### **기본 ViT 구조**
- **패치 기반 처리**: 이미지를 패치로 분할하여 시퀀스로 처리
- **Self-Attention 메커니즘**: 전역적 의존성 모델링
- **위치 인코딩**: 공간적 정보 보존

#### **SVTRv2 (Scene Text Recognition with Vision Transformer)**
- **핵심 개선사항**:
  - CTC 기반 접근법으로 빠른 추론 속도
  - 다중 크기 리사이징 전략으로 텍스트 왜곡 방지
  - Feature Rearrangement Module로 CTC 요구사항 충족
  - Semantic Guidance Module로 언어학적 컨텍스트 통합

- **성능 우위**:
  - 대부분의 Encoder-Decoder 모델보다 우수한 정확도
  - 추론 속도에서 현저한 개선
  - 다양한 텍스트 불규칙성 처리 가능

### 2.2 TrOCR 계열 모델

#### **DLoRA-TrOCR**
- **효율적 파라미터 미세조정**: 전체 파라미터의 0.7%만 훈련 가능
- **하이브리드 아키텍처**: 
  - 이미지 인코더에 DoRA 모듈
  - 텍스트 디코더에 LoRA 모듈
- **성능 지표**:
  - IAM 데이터셋: CER 4.02
  - SROIE 데이터셋: F1 score 94.29
  - STR Benchmark: WAR 86.70

#### **Cascaded-Transformers**
- **효율성 개선**: 인코딩 과정에서 점진적 토큰 크기 감소
- **계산 복잡도**: 50% 감소하면서 정확도 유지 (92.77% → 92.68%)
- **실용성**: 리소스 제약 환경에서의 배포 가능

### 2.3 위치 기반 Transformer

#### **LOCR (Location-Guided Transformer)**
- **혁신적 접근법**: 텍스트와 위치 정보의 동시 자동회귀
- **핵심 기능**:
  - 위치 가이드 디코딩
  - 반복 문제 해결 (4.4% → 0.5%)
  - 대화형 OCR 모드 지원

- **성능 개선**:
  - 편집 거리: 25% 개선
  - BLEU 점수: 0.827 달성
  - F1 점수: 0.897 달성

## 3. 하이브리드 접근법

### 3.1 CNN-Transformer 융합

#### **DOTA (Deformable Optimized Transformer Architecture)**
- **아키텍처**: ResNet + Vision Transformer 백본 결합
- **고급 기법**:
  - Deformable Convolutions (3, 4번째 블록에 적용)
  - Retrieval-Augmented Generation
  - Conditional Random Fields (CRF)
  - Adaptive Dropout

- **벤치마크 성능**:
  - IC13: 97.32%
  - IC15: 58.26%
  - SVT: 88.10%
  - IIIT5K: 74.13%
  - SVTP: 82.17%
  - CUTE80: 66.67%
  - 평균 정확도: 77.77%

### 3.2 Attention 메커니즘 최적화

#### **Multi-channel Attention Networks**
- **앙상블 전이 학습**: Inception Net + ResNet 특징 융합
- **성능**: 전처리된 데이터셋에서 98.00% 정확도
- **특징**: 문맥 정보를 위한 어텐션 모듈 적용

## 결론

OCR을 위한 특징 추출 기법은 CNN에서 Transformer로, 단일 모델에서 하이브리드 접근법으로 발전하고 있다. 현재 가장 유망한 방향은:

1. **경량화된 Transformer 모델**: 효율성과 성능의 균형
2. **위치 기반 가이드**: 반복 문제 해결 및 정확도 향상  
3. **다중 모달 융합**: 텍스트, 위치, 의미 정보의 통합
4. **실시간 최적화**: 실용적 배포를 위한 속도 개선

특히 한국어와 같은 복잡한 문자 체계에서는 언어별 특성을 반영한 전용 아키텍처 개발이 필수적이며, 실제 배포 환경에서의 제약사항을 고려한 최적화 기법이 점점 더 중요해지고 있다.
